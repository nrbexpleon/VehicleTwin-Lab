# Security policy

Report vulnerabilities privately through GitHub Security Advisories. Do not place exploits, credentials, client information, vehicle identifiers, private keys, or sensitive traces in public issues.

Supported development line: `0.1.x`.

The lab binds to loopback by default. Set `API_TOKEN` from a secret manager for authenticated API use. Do not bridge it to a physical vehicle or actuator network without an independently reviewed safety and cybersecurity architecture.
